# Adversarial cross-field candidate review

Status: 4 October 2026. This is a challenge document, not an approval of a preferred idea. Candidate details and primary sources are in [Cross-field inventions](../CROSS_FIELD_INVENTIONS.md) and [source notes](../sources/CROSS_FIELD_SOURCES.md).

## Historical transition receipts

**Hostile reduction:** this is ordinary CDC before-/after-images plus a context ablation. Databases have done it for decades. CIR already distinguishes information from the act of recovery. StateAuditor explicitly constructs old/current transitions and includes matched no-transition controls. An LLM receiving more relevant information and doing better is unsurprising.

**What could survive:** a finding that apparently stale historical information changes the sign or magnitude of the retention tradeoff, despite identical current facts. The useful distinction is between historical evidence for adjusting work and obsolete assertions about the present. It could explain why indiscriminate cleanup can remove a resource necessary for cheap revision. The project must show this distinction matters in naturally generated collaborative histories, not only a hand-built arithmetic example.

**Observation audit required:** enumerate the exact prompt-visible old value under B and C, including message prose, candidates, correction rendering, source IDs and tombstone fields. A source version stored offline is not model-visible. Conversely, an edge ID that encodes endpoints may already reveal the whole deleted edge. Report exact syntax and examples; do not count redundant receipts as new information.

**Candidate correctness caveat:** a useful incremental update requires a useful old summary. Do not filter the main sample to successful prefixes; report all worlds and the predeclared correct-prefix subset. If the effect appears only after replacing model summaries with gold, abandon the deployable contribution and label that experiment oracle-assisted diagnosis.

**Clean comparison:** identical current sources, original history fixed, same scheduled calls and communication tools, same old/new edit, same notice structure with historical field present versus **“not included in this receipt,”** tokenizer-matched neutral control. Do not say the old value is globally unavailable; it may be in history or reconstructible. No special formula, target coordinate, answer, or relevance selector. This is a receipt-interface intervention; padding does not equate salience or attention, and the comparison cannot isolate a hidden mental process.

**Minimum plan after review:** B/C and BΔ/CΔ on every existing main Prefix Sum/Sort world, fixed before inference: 12 or 16 paired clusters, 384 or 512 extra calls. The sole focused secondary is `eta_1=(a[CΔ,1]-a[BΔ,1])-(a[C,1]-a[B,1])`, where a is the fraction of peers with a completely correct first-round candidate. Use equal two-family weighting while keeping the PS six-family theta as the only primary estimand. Negative eta_1 means B benefits more from the receipt than C before newly generated recovery messages can arrive. Continue every branch for four rounds and report `eta_A=(A[CΔ]-A[BΔ])-(A[C]-A[B])` as a mandatory descriptive companion, not a second endpoint from which to select a favorable result. Exact outputs and pre-existing D/U diagnostics reveal whether old-value injection helps updating or simply causes copying. Add no-change receipt controls only if the claim extends to a correction-specific receipt effect beyond a generic extra-notice effect; do not claim that stronger estimand from unrun siblings.

**Why narrow the live test:** maximum's correct old output already determines the old changed value under the main-edit selection rule; differences plus an unaffected raw anchor reconstruct the old array. Prefix and sort better expose distributed historical-input gaps. Do not average all these regimes and announce an empirical law from six/eight worlds per task. CPU analysis of all six is retained, and exact prefix/sort results may still be mixed.

**Inference limits:** eta_1 is secondary and has only 12/16 independent world clusters. The first-round endpoint follows the local pre-new-message information boundary; it does not promise better power. If eta_A=eta_1/4 for every world, its SD is also quartered and the standardized effect is unchanged. Two-sided intervals must be shown even if wide; no significance claim from treating individual peers or rounds as independent. A favorable result on one family and not the other is a bounded result, not cross-domain dominance. A null cannot distinguish zero practical effect from insufficient precision without interval evidence.

**Mechanism and interaction limits:** a demonstrated direct first-round gain establishes more correct responses before newly generated recovery messages arrive. It does not by itself establish avoided communication, avoided recomputation, or a recovery-latency mechanism; those need trace evidence, and salience remains an alternative. A near-zero eta_1 concerns only the immediate retention interaction; eta_A and the full trajectories answer separate questions. A near-zero eta_A may also reflect later cancellation, not merely a fading early effect. Both histories can receive equally large direct benefits and yield zero interaction, so receipts are not shown unnecessary by either zero interaction. Conversely, a negative interaction can arise because B is harmed less than C; report the direct effects before claiming improvement.

**Abandon or narrow:** if the preimage is already recoverable from every actual boundary view, abandon the information-deficit claim, though easier retrieval or presentation may still matter. If almost no useful summaries survive, abandon a summary-adjustment explanation. Distinguishing semantic content from every attention/wording effect requires controls beyond the minimal factorial; do not pretend they have been run. Reject a practical default if harm exceeds benefit, a mechanism if it grows into hand-written task-specific delta solvers, or the live extension if funding it sacrifices the original study. In particular, preserve an affordable 48-world core rather than reducing it to 36 to buy the addition.

**Useful negative result:** clear current evidence plus a cheap restart may eliminate any practical need for historical receipts in this regime. Another useful result is that before-images only help an output-only representation and not unrestricted prose, but that requires actually running the relevant arm.

## Update sufficiency / candidate-only retention

**Hostile reduction:** self-maintainable views, incremental dynamic algorithms and answer-only communication. Full sort output is just the full multiset in a new order, so successful reuse may be evidence recycling rather than reused reasoning. Prefix outputs can encode original inputs invertibly. Calling these compressed reasoning is misleading.

**What survives:** a representation-aware boundary about what different retained states make possible. It is important to distinguish source availability, invertible encodings, noninvertible summaries and incorrect model artifacts. A useful benchmark teaches these distinctions even if no new policy wins.

**Fatal shortcuts:** assume old value in the notice; treat global output union as each peer's private view; treat old gold as a runtime object; claim different families identify a causal sufficiency law; regress on many correlated task properties with only 36–48 independent worlds.

**Smallest justified use:** a formal table and constructed counterexamples, with CPU checks if useful; no GPU arm until actual prefix artifacts make the candidate substantive. If added, candidate-only needs its own sham branch to distinguish generic context shortening from revision-specific retention.

## Temporal exposure cones

**Hostile reduction:** classical transitive invalidation / rollback dependence. Current PlanFence, REVISE, APPA, ESC-CR and NeuroTaint already discuss broad contexts and missing precise provenance.

**What survives:** measuring how rapidly derived-object selectivity becomes useless under a specific collaboration protocol, alongside exact changed-output coverage. These have different units: a call/history cone versus output coordinates. Their sizes cannot form an overinvalidation ratio or demonstrate that exposed history is semantically invalid. A negative result can say the runtime observation is too coarse, not that every exposed sentence is stale.

**Falsifier:** if all useful history is conservatively exposed before the correction, a selective reset equals C. Do not run an identical arm or adjust the prefix to create desired selectivity after seeing outcomes. If graph filtering helps only by removing an equal amount of text, matched random/recency deletion captures the result.

**Guarantee caveat:** a narrow bound on represented derived-object dependence requires complete prompt/source/message logging and isolated recurrent/KV state. The old fact may still influence source acquisition, selection, routing or ordering in the retained evidence table. Removing derived objects from the cone therefore does not establish full noninterference, current validity of retained claims, or exact equivalence to a never-observed counterfactual.

## Fault containment, hysteresis and adaptive recovery

- Integrated collateral damage is scientifically useful but already implicit in the PS; promote it to a clearer report, not a new central algorithm.
- Revision cycles create an interesting same-final-truth test, but equal current facts are not equal observations, work or histories. Additional controls are substantial.
- Fixed delayed reset is a baseline. A learned reset router is prior art and data-hungry. Universal restart guarantees do not apply without recognizable correctness. Disagreement may signal healthy correction, while wrong consensus may hide failure.

## Decision standard

Prefer the historical-information experiment only if it survives a CPU/prompt observation audit and a small bounded development check. Preserve the possibility that its cleanest outcome is a null. The cheapest valid outcome is a stronger interpretation of the original PS plus an exposure/sufficiency analysis; no new method should be added merely to create a title.
