- ICR's anonymous code URL returned an empty text page through the reader. Do not describe its implementation as audited or reproduced.
- TRACE GitHub API repository/tree requests succeeded. Main branch and last push were observed; source snippets inspected later are recorded separately if used. A repository tree is not an implementation-level verification of all paper claims.
- A third-party CIR page said “last updated October 2.” The primary submission history has only v1 September 30. The later label is excluded from publication/revision claims.
- Product blogs, Reddit discussions, search snippets and aggregator performance claims were not technical evidence. Leto training recovery was screened as a different workload, not a direct agent-semantic predecessor.
- Prior OpenReview “Repair Sets Before Repair Choices” and PACMI access uncertainties remain unresolved by this sub-investigation; do not upgrade their earlier evidence status.

## Claim discipline

Source-reported numerical results are not reproduced results. Similar terminology is insufficient to establish equivalence; the reduction must specify runtime observations and output guarantees. Conversely, different application objects do not establish novelty if the same dependency-recovery algorithm can act on them. Every positive gap statement in the source note is conditional on this search's coverage and on a decisive experiment.
