# Lessons learned

## Initial guardrails

- A good correction benchmark is not automatically a reusable recovery contribution.
- Source delivery, reasoning revision, and safe reuse are distinct capabilities.
- Existing documentation is evidence about project intent, not proof that an experiment or literature claim is correct.
- Keep scientific value under a null result explicit from the start.

## Findings that must survive context loss

- REVISE tracks structured control and collection-membership reads automatically. Do not describe it as positive-only or dependent solely on handwritten edges.
- Clearing memory, quarantine, revalidation, version fencing and selective replay all have direct agent precedents. A combination needs a specifically unestablished capability and evidence.
- Exact behavioral erasure and current-task correctness are different goals. For ordinary correction, historically influenced work may remain legitimately useful.
- A valid path does not prove it is still shortest; a feasible choice does not prove newly eligible choices were considered. Artifact validity and search adequacy need different evidence.
- Negative dependencies and reinstating pruned choices are classical ideas. Missing search obligations in opaque agents are a possible empirical gap, not an invented theory.
- A checker that computes the answer can manufacture apparent agent recovery. Equalize access, charge its cost, and include a deterministic non-agent baseline.
- Missing metadata should expand reconsideration, never certify independence. But a broad fallback must be compared with simply using that fallback everywhere.
- Native SILO has more state than prompts: submissions, message read cursors, persisted files and shared-file conflicts all affect branching semantics. Fresh CPU audit documents these.
- More than one month of implementation time is available; the fixed compute budget still requires replacing secondary comparisons rather than adding every promising arm.
