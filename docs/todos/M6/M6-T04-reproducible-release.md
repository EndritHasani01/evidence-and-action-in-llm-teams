## Intended outcome

A clean environment can reproduce the released evidence without GPU calls, and the concrete reviewed bundle is published only within explicit authorization.

## Scope and boundaries

- Prepare one canonical run bundle with accepted lock/configuration/system facts, exact prompts/templates, actual worlds/edits/ownership/partitions/seeds/schedule, immutable prefixes/branch states, raw calls/attempts/deliveries, pilot/allocation/coverage/deviation reports, tidy outcome/cost/annotation tables, analysis code, figures and report.
- Include raw generated IDs, termination, replay relationships, analysis/case/rubric settings and source attribution through the existing records. Exports are reproducible views, not additional truth stores.
- Document clean installation, CPU validation, prepare, frozen execution/resume/status and offline analyze/export commands in the project README. Document stochastic rerunning separately with environment/device limits; do not promise token-identical regeneration.
- Verify backups after clean checkpoint/close, dependencies and all artifact links in a fresh environment. Reproduce tables, case IDs and plotting inputs without inference.
- Prepare all safe local release work before requesting publication approval. Publication and any paid rerun or frozen-design change require explicit applicable authorization; reuse existing scope when already authorized.
- Limited route: package audited feasibility or incomplete-run evidence with missing artifacts/outstanding work explicit. Never invent an accepted freeze or describe it as a completed empirical study.

## Completion criteria

- A clean offline reproduction passes and a release inventory accounts for every required present or explicitly unavailable artifact.
- Concrete local bundle/report/destination and publication scope are reviewable before the final authorization step. Until publication is authorized/executed, leave this task active or blocked with local readiness evidence.
- Authorized publication succeeds with a verified destination/version and accessible released evidence; preserve the canonical local bundle.
- Update the plan's progress and retrospective with accepted configuration if any, achieved coverage, artifact location, reproduction result, deviations, total resources and remaining limits.
- M6/study completion requires the entire frozen schedule completed, passed audit and release checks. A limited release can finish this task while M6-T01 or M5 gates remain blocked; it cannot close the intended study.
