## Intended outcome

A concrete local course report/artifact release reproduces audited tables, selected cases and plotting inputs in a clean CPU environment without new inference.

## Scope and boundaries

- Assemble the one canonical complete or limited evidence bundle: accepted lock/configuration/system facts where available; exact prompts/templates; actual worlds/edits/seeds/manifests; immutable prefixes/branch states; raw IDs/text/calls/attempts/deliveries/replay parents; pilot/allocation/coverage/deviation reports; tidy outcome/cost/annotation tables; analysis source, figures and report.
- Preserve earlier/superseded artifacts and original unknowns. Derived exports are reproducible views, not another mutable truth store or custom identity system. Include source/data attribution and applicable redistribution limits without bundling credentials or unrelated private files.
- Document actual clean installation, CPU validation, course preparation, frozen execution/resume/status and offline analysis/export commands using the existing supported paths. For a feasibility-only release, mark unavailable main commands/configuration accordingly rather than inventing an accepted freeze.
- Reproduce in a clean environment without GPU allocation, model weights or inference calls. Verify two runs yield identical tables, selected case IDs and deterministic plotting inputs; inspect rendered report/figure exports and independently reopen the ordinary backup.
- Separately document stochastic rerun instructions and environment/device limits. Equal seeds do not promise identical tokens; no retraining, extra model arm or fresh expensive validation belongs to local release preparation.
- Prepare the concrete reviewable release before external approval. Local readiness is separate from public publication, messaging or course submission.

## Completion criteria

- The portable local bundle and clean-environment reproduction pass, with complete instructions and preserved canonical provenance.
- Artifacts/figures/report are internally consistent and correctly labeled full or limited; all links, scope, limitations and outstanding thesis work are visible.
- The exact deliverable and permissible delivery scope are reviewable. No external publication/submission has been claimed by local preparation alone.

## Validation and evidence

Execute the documented clean CPU installation and offline commands, compare table/case/plot inputs twice, check exports and source references, and reopen the backup. Record commands, environment, comparisons, release contents/location and remaining external authorization; do not duplicate already passed checks without a new concern.
