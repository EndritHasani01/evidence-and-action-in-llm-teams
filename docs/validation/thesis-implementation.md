## Verification environment

Windows 11, Python 3.11.9 virtual environment (`.venv`), CPU-only torch
2.11.0+cpu, transformers 5.12.0, tokenizers 0.22.2, huggingface-hub 1.19.0,
numpy 2.4.6. The Kaggle runtime is Python 3.13 with the pinned
`configs/i01-runtime.lock`; the thesis code uses no feature newer than Python
3.11 except `tarfile` extraction filters in the notebook's first cell, which
need Python 3.12 or later and so run only on Kaggle.

## Regression of existing tests

The full repository suite (`python -m unittest discover -s tests`) ran 704 tests
in 38 minutes: 698 passed, 1 skipped, 4 failed and 2 errored. All six are
course-era tests and also fail on a clean checkout of the parent commit
`5d1d477` without any thesis change:

| Test | On clean `5d1d477` |
|---|---|
| `test_i01_course3_repairs` (2 tests) | Same failure: the historical course-3 continuation refuses the current checkout as an unreviewed source |
| `test_course_online_bootstrap` (2 tests), `test_course_repair.test_known_hardware_defect_stops_before_cold_setup_downloads` | Same failures |
| `test_course_simplified_workflow.test_measured_hardware_acceptance_still_requires_complete_probes_cache_and_headroom` | Passes alone on both trees; fails on both trees when the course modules run together (order-dependent within course tests) |

(215 tests, 3 failures and 1 error). The thesis work changed no file these
tests exercise; it adds `recovery/thesis/`, which the course-3 source audit also
lists alongside the many pre-existing differences.
