# Prioritized design decisions and practical future tests

**Candidate for the next approval session. Not adopted, implemented, frozen or
authorized for execution.** The literature supports the priorities below; exact
effects and runtime remain unknown.

## 1. Decide the main scientific question

Recommended question:

> With useful historical source evidence already supplied, does removing an
> explicit old commitment improve recovery after a private information change,
> and can the team communicate a new value when that value is necessary?

The result concerns bounded two-agent continuation, not general long-term memory
or spontaneous team formation. Either model may benefit, be harmed, show little
difference, or fail the capability gate. A clear negative or inconclusive result
with adequate diagnostics is preferable to increasing conditions until one wins.

| Alternative | Main advantage | Main weakness | Decision |
|---|---|---|---|
| Original five-family/four-peer thesis | Broad task structures and teammate-reset effects; extensive CPU code exists | Qualification and long-context risks; small per-family samples | Preserve for later; do not execute twice now |
| Current six-cell, two-trial proposal | Empty-history comparison and uniform replication | Withdrawal shortcut; substantial repeat/arm cost; interaction can obscure practical benefit | Revise explicitly before adoption |
| Natural retain/clear only | Closest to executed course and natural histories | Policy difference bundles lost evidence and removed commitments; poor prefixes dilute interpretation | Use a small, separately reported bridge |
| **Four controlled cells plus bounded checks** | Literal contrast, interpretable endpoint, more independent worlds | Narrow supplied-history claim; cue-length mechanism unresolved | **Preferred** |
| Forced exchange or host solver | Likely easier to complete and diagnose | Supplies strategy or answer; changes the task | Exclude from main comparison |

A strong alternative is to retain H0 in all worlds but use one primary trial:
160 worlds, six cells, the same 24-world repeat panel, 32-world bridge and
three-packet preserving probe give 20,672 attempts including the allowances
below. This directly estimates historical-evidence utility as a secondary
comparison and may be preferable if that is essential to the thesis claim.
It has fewer independent worlds for the commitment comparison and a tighter
runtime constraint. The four-cell recommendation deliberately chooses the
narrower question. It does not establish empirically that source evidence is
better than empty history. Nor do the course traces establish that an explicit
old commitment is the dominant failure cause; the study tests a policy effect,
and its explanation must remain conditional on the observed results.

## 2. Preferred controlled experiment

Use the existing two-agent maximum task, current private source authority,
ordinary messages, private irreversible submissions, waiting and at most three
calls per agent. Reuse the proposed legal scripted original exchange and its
historical fields. HS contains both complete indexed original shard reports;
HSC contains exactly those source bytes plus the agent's own correct historical
submission. The old submission was correct when made. No new model prefix is
fabricated or credited as executed work.

| Cell | Historical packet | Current event |
|---|---|---|
| 1 | HS: source reports | Announced private revision |
| 2 | HSC: same reports plus old commitment | Same revision |
| 3 | HS | No change, with truthful continuation notice |
| 4 | HSC | Same no-change episode |

Every declared continuation boundary, including no change, opens a fresh phase
for both peers and resets the phase's call/submission state. Historical final
submissions remain final in their old phase. The common prompt must say this
explicitly: the course rule that only a source revision reopens agents cannot
be copied unchanged into sham episodes. This is a prospective scientific rule,
not a reinterpretation of the completed campaigns.

Generate **192 independent controlled worlds**, balanced over two edit strata,
two owners and two first speakers: eight strata, 24 worlds each. Every world
receives all four cells and both models. Edits target the old unique winner:

1. **Winner demoted:** replacement is below M2, the largest remaining value.
2. **Winner remains:** replacement is above M2 and different from the old M1.

Both strata change the numerical answer. Assign the stratum prospectively and
hide it from peers. Use the same bounded integer range unless an explicit
amendment chooses otherwise. Require both edit types to be legal for generated
worlds, including at the integer ceiling; fix rejection rules and disclose the
conditioned population. Never condition on model performance.

Use one primary continuation trial per cell. Select 24 worlds in advance,
three per stratum, for two extra trials in all cells and models. The **primary
analysis uses trial 0 for every world**. The repeat panel describes sampling
stability and paired gain/loss changes. It does not become 72 independent worlds
or a best-of-three score.

The primary effect is HS minus HSC revised-world joint exact success, estimated
separately for each fixed model system. Give each a 97.5% paired world interval.
Report no-change means, the interaction, edit-stratum estimates, model-effect
difference, gains/losses and costs as secondary/descriptive results. Do not add
a separate primary test for every stratum or trace label.

## 3. Keep only two small checks

**Natural-history bridge: 32 disjoint worlds.** Acquire each model's actual
original episode, then fork retain/clear under revision/no change, as in the
previous proposal. Balance edit strata, owner and first speaker. Include every
prefix, including failed ones. Use one continuation trial; report the
prefix-plus-continuation cost and conditional descriptions. Different models
produce different prefixes, so this is not the same-history cross-model test.
Its retention contrast also differs from HS/HSC. Do not pool it into the primary
effect or require a favorable bridge result to publish the controlled result.

**Real answer-preserving probe: 32 fixed controlled worlds.** Change a nonwinning
record while keeping it below the old maximum, and run HS/HSC once each with a
full-information scalar control. The answer remains correct despite a real
edit. Use a predetermined subset balanced over the eight main strata. Treat
overlap with main worlds as intentional; bootstrap it separately with preserved
identities. Its purpose is diagnostic preservation, not another powered policy
ranking.

Exclude H0 from the preferred main schedule. Empty history is scientifically
interesting when the question is the value of historical source evidence, but
it consumes one-third of the previous controlled factorial. Here the direct
question concerns an old commitment given useful evidence. If H0 is prioritized
instead, replace a lower-priority check or adopt a different explicitly costed
question; do not silently append it.

## 4. Future tests in priority order

| Priority | Test and falsifiable question | Acceptance / informative failure | Cost and complexity |
|---|---|---|---|
| P0 | CPU information witness: can the non-owner distinguish legal winner-remains replacements before a new message? | Two legal worlds with identical initial non-owner views and different gold; owner can solve each | Deterministic, low; no inference |
| P0 | Packet/view/protocol audit: does only the declared historical field differ? | Literal report equality; no truth, edit-stratum or future-value leakage; legal scripted exchange; truthful reopening | Focused deterministic checks; reuse existing runner/tests |
| P0 | Precision decision before adoption | Accept large-effect/coarse-bound inference; reject this sample if reliable 5-point detection is required | Analytic sensitivity only; no favorable-effect gate |
| P0 | Separate model qualification: can each configured system extract current values and execute legal actions? | Proposed existing gates: 11/12 scalar qualification, 7/8 diagnostic targets; no numerical feedback or answer repair | Bounded GPU development only after explicit authorization |
| P0 | Twelve disjoint pilot worlds: is the common interface useful under both edit types? | 22/24 scalar controls; HS/HSC sham each at least 9/12; at least 98% legal calls; finite outputs and complete accounting | Same bounded development ceiling for both models; descriptive usefulness gate |
| P1 | Main HS/HSC comparison: does commitment removal change revised joint success? | Complete paired coverage and declared intervals; either sign or inconclusive result accepted | Four cells, one primary trial, two models |
| P1 | Repeated panel: do the same policy gains recur? | All scheduled trials reported; no best-trial selection | 24 fixed worlds, two extra trials per cell |
| P1 | Natural bridge and preserving probe | Size and direction reported with uncertainty; no favorable-result veto | Fixed small samples; no automatic expansion |
| P2 | One common source-layout or strategy alternative if development fails | Compare to current prompt on disjoint development worlds with equal call budgets; then seek approval for a changed freeze | One bounded alternative; no open-ended prompt search |
| Defer | Prefix Sum/Top-K transfer, mixed teammate resets, longer horizons or a common-decoding sensitivity arm | New question, population, capability and resource case | Separate scientific amendment and campaign |

Gate thresholds are screening rules, not confidence guarantees. They must not
select worlds, select a favorable retention effect, or conceal failure of one
model. A second development candidate is a separately declared scope, not a new
500/17,000-attempt budget created by renaming an output folder.

## 5. Complete planning arithmetic

Worst-case first-attempt slots below assume six calls per team episode and no
savings from early submission or deadlock. Models and continuation cells do not
share generated replies. Natural prefixes are physically acquired once.

| Component | Both-model slots |
|---|---:|
| Main: 192 × 4 cells × 6 calls × 2 models | 9,216 |
| Main original/revised full-information controls: 192 × 2 × 2 | 768 |
| Repeat panel: 24 × 4 cells × 2 extra trials × 6 × 2 | 2,304 |
| Natural bridge: 32 × (6 prefix + 4×6 recovery + 2 controls) × 2 | 2,048 |
| Preserving probe: 32 × (2 packets × 6 + 1 control) × 2 | 832 |
| **Main and bounded checks** | **15,168** |
| Provisional development/readiness ceiling, retained as a planning reserve | 1,112 |
| Additional reload readiness ceiling | 80 |
| Infrastructure/reconciliation contingency ceiling | 600 |
| **Total ceiling allocation** | **16,960** |

Round the requested limit up to **17,000 attempts**. The 1,112 development figure
is a conservative inherited allowance, not an executable new manifest. Derive
the exact new stage schedule after deciding the design and before authorization;
do not silently expand it. Retries and uncertain work consume contingency under
the existing accounting rules. Neither failed scientific replies nor completed
invalid actions are resampled as infrastructure errors.

This is smaller than the previous 24,000-attempt target, while expanding the
independent controlled cohort. It changes scientific scope, rather than claiming
an optimization with identical coverage. The
[resource sensitivity](evaluation-statistics-and-compute.md#8-conservative-resource-planning)
shows that a proposed 200 aggregate GPU-hours is still conditional on measured
runtime. Under the conservative formula, 30 seconds per attempt exceeds it.

If the budget cannot support 192 worlds, prefer an explicitly adopted nested
128-world fallback, 16 per stratum, before main outcomes. Keep the 24-world
repeat panel and bounded checks fixed for simplicity. Its controlled main and
scalar slots drop by 3,328, giving 13,632 total allowance. Precision worsens;
the fallback is not a license to stop at a favorable intermediate result. The
main-stage decision must use resource evidence and the agreed precision floor,
not the estimated retention effect.

## 6. Required amendments and authorization sequence

| Decision needing explicit adoption | What changes from existing authority/proposals |
|---|---|
| Scope | New two-agent thesis regime; original four-peer and course contracts remain historical/adopted within their own scopes |
| Population | Two edit strata, common mathematical eligibility, eight assignment strata and their weights |
| Policies and events | HS/HSC main; H0 excluded; truthful no-change reopening and real preserving probe |
| Main estimand | Direct revised-world effect per model; previous interaction becomes secondary |
| Sampling | 192/128 pre-outcome choice; one primary trial; 24-world three-trial panel; separate bridge/probe |
| Models | Exact checkpoint/tokenizer revisions, direct-answer mode, precision, complete generation settings and context limits |
| Resources | Provisional 17,000 attempts and requested 200 additional aggregate GPU-hours; no implied reset of historical spending |
| Analysis | World pairing/strata, multiplicity, bounded companions, missingness, process-panel and cost scope |

1. **Next session: approve or revise the scientific candidate.** Research
   acceptance alone does not change the specification.
2. **Separately authorize CPU implementation.** Adopt the explicit specification
   amendment and update the existing roadmap then. Reuse I-01 persistence,
   raw outcomes, fixed IDs and reporting. Implement the new generator/view,
   packet and schedule seams and two explicit model paths. No generic registry,
   semantic graph or new storage service is needed.
3. **Review deterministic acceptance evidence.** Exact truth, legal views,
   literal packet transformation, restart/replay and cost accounting must pass.
   Passing tests is not GPU authorization.
4. **Authorize a bounded GPU development stage with its complete scope/cost.**
   Qualify both systems and the actual hardware. Preserve failed qualification.
   Require worst permitted context/output capacity, finite outputs, no offload,
   isolated per-call state and at least the existing 1.5 GiB headroom gate.
5. **Freeze and seek separate main authorization.** Decide target/fallback using
   runtime and precision gates before main outcomes; inspect the complete slot
   manifest and conservative forecast. Paid booking remains separately explicit.
6. **Analyze and report all scheduled outcomes.** Preserve missingness and
   unfavorable results. Publication is a later authorization boundary.

This sequence preserves completed course results, original thesis evidence and
every existing freeze. It makes the next approval a concrete scientific decision
without executing or implementing an unapproved change now.
