## 3. What the existing thesis designs get right

The adopted original thesis already separates current source authority from
historical derived work, includes no-change and real answer-preserving controls,
preserves failed prefixes, defines exact replay, distinguishes failures from
unknown slots, and treats the world as the analysis unit. These are strengths to
retain. The original teammate-reset estimand is also meaningful: an intervention
can change what a retained collaborator receives.

The 18 October proposal improves feasibility by using the demonstrated I-01
system and two models, explicitly supplied histories, literal packet differences
and fixed repeated trials. It correctly treats model systems as configured
systems and the natural bridge as a separate population. Its hardware gates and
physical-versus-policy accounting should survive any revision.

Neither design should be adopted merely because its code or prose is extensive.
The original matrix spreads a small number of worlds across heterogeneous tasks
and many comparisons. The proposed matrix narrows tasks but allocates substantial
compute to an empty-history arm and universal repeats before establishing what
effect size those expenditures can resolve.

## 4. Two information-structure problems to resolve

### Complete historical reports partly centralize the recovery

Under HS, both agents receive both complete original indexed shard reports.
After one private edit, the owner has its complete current shard and a complete,
unchanged remote shard. It can compute the current global maximum on its first
call. This remains a team task because the partner must receive sufficient
information and both private submissions must finish. It is not a test of
discovering all distributed evidence afresh.

This is a defensible controlled experiment about **continuation conditional on
shared historical evidence**. It cannot establish that a model naturally creates
or maintains that evidence. Natural and supplied histories answer different
questions; selecting successful natural prefixes would introduce another
population change. Include all bridge prefixes, with correctness-stratified
descriptions only after the main denominator is fixed.

### The withdrawal-only population permits an answer shortcut

Let the old unique winner be M1 and the largest remaining value be M2. Existing
I-01 generation enforces `replacement < M2`. Therefore the revised answer is
always M2. In HS/HSC, M2 is in the historical tables. Removing the changed row
gives the scored answer without reading its replacement.

The eligibility rule is hidden, so this shortcut is not logically warranted by
the public task instructions. Nevertheless, exact outcome scoring will credit
it when it happens to be correct. Do not retroactively change that score or
assert the model used the shortcut without evidence.

An illustrative counterexample shows the design issue without running anything:
old shards `[90,80]` and `[70,60]`, with the first record edited. Replacement 10
makes 80 correct; replacement 95 makes 95 correct. Before an owner's new message,
the non-owner can have the same current shard, historical tables and record
notice in both worlds. It cannot determine which answer is current. A population
containing only the first kind does not test that distinction.

**Preferred amendment:** balance edits below M2 with edits above M2 that differ
from M1. Both change the numerical answer. In the second stratum the edited
record remains the winner, and its new value must reach the teammate for
evidence-grounded success. The edit stratum stays evaluator-only. Fix legal
ranges, ties, eligibility, rejection caps and stratum weights before generating
main worlds. At the bounded integer ceiling, some worlds have no alternative
above M2; handle that mathematically, without model-outcome screening.

## 5. Primary contrast, mechanisms and claims

For packet policy P and event E, let `mu(P,E)` be expected joint exact success.
The previous proposal makes the interaction primary:

`theta = [mu(HS,revision)-mu(HSC,revision)]
       - [mu(HS,no-change)-mu(HSC,no-change)]`.

Suppose both revised-world rates are .40, while HS no-change is .60 and HSC
no-change is .90. Theta is +.30 despite zero recovery benefit from removing the
commitment. This is a mathematical example, not simulated evidence.

Prefer the direct revised-world difference as the practical primary estimand;
keep theta and every cell mean as explanatory companions. The literal
intervention removes the separate historical commitment field. It also changes
length, repetition and salience. It does not identify a pure psychological
anchoring mechanism. The old winning value still appears in the HS source
tables. A padded or paraphrased control is justified only if a later claim needs
to distinguish those mechanisms.

Keep no-change episodes: they test whether a policy damages valid work and
whether reopening itself causes failure. Their notice differs truthfully from
an announced real revision, so event contrasts concern the declared
notice-plus-source package. A real answer-preserving edit adds a different
diagnostic: appropriate persistence despite an actual source change.

These recommendations require a new approved specification section. They do not
erase the original four-peer scientific questions or convert course findings
into thesis results.
