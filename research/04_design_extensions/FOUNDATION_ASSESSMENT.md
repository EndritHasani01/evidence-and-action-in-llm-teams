# Foundation assessment

Assessment date: 2026-10-04. Governing source: [PROJECT_SPECIFICATION.md](../../PROJECT_SPECIFICATION.md), read in full. This is a design assessment, not an evaluation of completed LLM runs.

## What the study already gets right

The scientific object is a team that has already invested in a joint computation when an authoritative input changes. Its unusually useful feature is intervention on **the same realized collaboration**, rather than comparison of independently sampled successful and unsuccessful teams. A four-round prefix is frozen after round-four delivery; independent four-round continuations inherit precisely defined state. Peers continue after submitting an answer. These details preserve a meaningful recovery opportunity and avoid attributing different initial work to the recovery policy.

Four identical peers separate private observations from model identity. The six mathematical tasks vary aggregation, ordering, spatial output locality, and alternative paths, while retaining exact before/after evaluators. They do not constitute a controlled complexity ladder. Output placement matters: replicated maximum, top-K, difference and BFS differ from partitioned prefix and sort outputs.

| Asset | What it identifies or protects | What it does not establish |
|---|---|---|
| Shared prefix and sibling branches | Effects of interventions conditional on realized prior work | Repeated-seed robustness of each identical world |
| Private source shards | Evidence acquisition and coordination have operational meaning | Exclusively decentralized computation; centralization is permitted |
| Host-authenticated source forwarding | Which raw record/version was delivered, without transcription error | Which facts an LLM used semantically |
| Announced versioned correction | Recovery after diagnosed change | Detection of unannounced change or authority disputes |
| B versus L | Effect of guaranteed replacement-content delivery | Pure network latency or causal mediation by receipt time |
| C versus B | Effect of clearing derived history with CURRENT evidence held fixed | Pure anchoring, hidden-state erasure, or equality of historical information |
| C versus F | Value of previously acquired current raw evidence | Value of all information that may have been compressed into prose |
| Sham B/C | Separates change-dependent reset effects from ordinary reset effects | Elimination of every content/length interaction |
| Answer-preserving edits | Damage despite a real input change and unchanged target | Adequacy of every retained justification |
| Exact affected/unaffected coordinates | Repair, old-value retention, and collateral errors | Semantic dependency graph or proof of stale influence |
| Recovery trajectories | Temporary failures and speed under a fixed allowance | A deployable correctness-based stopping rule |
| Cost/protocol accounting | Failed slots and overhead cannot disappear from the result | Measured feasibility before the hardware pilot |
| World-level paired inference | Avoids treating peers, rounds and coordinates as independent samples | Precise task-specific laws with six/eight worlds per family |

The primary interaction is well chosen: `theta = mean[(C-B)_change - (C-B)_sham]`, using exact-agent recovery AUC. Both component contrasts must accompany it. Positive theta alone does not establish that reset is beneficial after change.

## What is already established elsewhere

Selective invalidation, conservative dependency tracking, source/conclusion separation, rollback, alternate-support preservation, and revision-aware execution all have predecessors. The earlier investigation's detailed corrections to REVISE's control/membership instrumentation must be retained. Its completion proposal is also explicitly an attributed synthesis, not a new theory of negative dependencies. The updated [landscape](UPDATED_RESEARCH_LANDSCAPE.md) records additional September 30/October 1 work on paired recovery outcomes and communication-content interventions.

Accordingly, neither matched continuations, source-preserving reset, nor measuring correction and preservation should carry a first-ever claim. Their conjunction with previously valid facts changing during private, multi-round collaboration is still a valuable controlled setting. The strength is identification and exact semantics, not the number of named policies.

## What keeps the current study from making a stronger explanatory contribution

The present policy contrasts identify useful package effects, but do not explain what representation of accumulated work makes recovery possible. B retains answers, intermediate calculations, obsolete assertions, potentially useful historical values, peer prose, and validation history together. C removes them together. A result can therefore show which package works without establishing which recoverable information the runtime should protect.

The six families already encode distinctions deeper than output-footprint size: whether old results plus a change determine the revised result; whether the required information is local or distributed; whether alternative candidates were compressed away; whether authentic evidence remains available; and whether conservative exposure covers nearly all derived history. These distinctions should be evaluated before adding a new runtime algorithm.

One concrete issue found during this investigation is temporal: a superseded value is unsuitable as a CURRENT fact but may remain accurate as a record of the PREVIOUS input. Prefix/difference updates can need that before-value to revise a retained numerical summary. The PS guarantees the new record, not a complete old-to-new transition record. B may incidentally retain the former value; C does not preserve its old source-table entry. This does **not** invalidate theta. It limits interpreting theta as a clean comparison of reasoning quality alone, which the PS already cautions against. This issue is being evaluated as a possible focused addition, not assumed to be an empirical explanation.

## Fixed components and change threshold

Preserve the central question, four peers, six families, immutable four-round prefixes, private evidence, authoritative revisions, exact evaluators, B/C/L/F, sham, answer-preserving diagnostics, failed-prefix inclusion, paired world inference, and bounded cost/protocol accounting. Preserve no oracle access in any policy. Keep the 30 aggregate allocated GPU-hour ceiling, Qwen3.5-9B initial plan, 4B fallback, and measured feasibility gates.

A proposed change must name the capability or ambiguity it isolates, the additional information it exposes, the baseline that receives equal access, the number of new calls, and the evidence lost if it replaces existing runs. A reduced world count increases uncertainty; an extra policy is not free because it reuses the prefix. Nothing in this investigation authorizes silently dropping sham branches, weaker model-validity gates, or a larger compute allocation.

The specification and earlier workspace remain untouched. Existing reference/support code is inherited background; it is not an implementation of this experiment.
