## Recommended call envelope

Each continuation has 16 calls. Run BΔ and CΔ only on the original Prefix Sum and Distributed Sort worlds. No new world, prefix, task family, reviewer, training run or full-information control is needed.

| Component | 48-world target | 36-world fallback |
|---|---:|---:|
| Original main matrix, intact | 5,856 | 4,488 |
| Focal worlds (two of six families) | 16 | 12 |
| Two new changed-event continuations | 512 | 384 |
| **Extended main total** | **6,368** | **4,872** |
| Increase over corresponding original matrix | 8.74% | 8.56% |
| 24-main-hour break-even average | 13.57 allocated s/call | 17.73 allocated s/call |

At an **illustrative**, not predicted, 15 allocated seconds/call, the additions cost 2.13 or 1.60 aggregate GPU-hours. With all six reserve hours counted, extended totals would be 32.53 hours for 48 worlds and 26.30 for 36. At 10 seconds/call they would be 23.69 and 19.53 hours; at 20 they would be 41.38 and 33.07. Thus “only two arms” does not guarantee fit.

These averages are presentation aids. Admission must use the PS's phase-specific measured means, slower-device treatment, 25% time margin, failed attempts, allocated idle time, and actual new prompt lengths. Two T4s shorten wall time only when both do useful work; they do not halve aggregate GPU-hours.

### Development budget

Keep the existing six development worlds and 588-call pilot. Add BΔ/CΔ on its **two predetermined prefix/sort development worlds**: 64 calls. The resulting pilot is 652 calls; including a separate maximum 24-call smoke screen gives a 676-call envelope for one passing configuration. At 15 allocated seconds/call that envelope is 2.82 hours before other development overhead. Its three-hour break-even is about 15.98 seconds/call. Failed model/backend probes consume the same three-hour development allowance; there is no automatic budget for completing a second full pilot.

Use CPU/mock cases for schema, temporal labels, branch isolation and malformed receipts. Do not spend GPU calls proving arithmetic identities. Preserve one aggregate hour for loading/setup and two for interruption/rerun reserve; total ceiling remains 30. If extended development cannot fit, keep the original pilot and deliver the information atlas without an admitted live extension.

## Budget-based decision order

1. Preserve the PS's model/capability gates and choose 9B/4B according to them, not according to a favorable recovery effect.
2. Establish which **original** complete schedule fits. If the original 48-world schedule fits, prioritize those 48 worlds. Add the focused extension only if its full cost also fits. Do **not** reduce to 36 solely to buy this exploratory diagnostic.
3. If the original 48-world schedule does not fit and the original 36-world fallback is admitted, append the 12-world focal diagnostic only if the combined schedule fits. Otherwise run the original 36-world study plus CPU/trace analyses.
4. Freeze this decision before main outcomes. Never take an apparent early null or positive eta as permission to alter coverage, add prompts, or spend reserve hours.
5. If unanticipated slowing prevents completion, follow the PS's hard stop and paired-coverage/bounded-sensitivity reporting. Do not silently drop difficult receipt branches or core sham cells.

This ordering deliberately values the original study's precision over buying a new label. The theoretical atlas and observable-state audit can strengthen the report even when no additional inference is affordable.

## Why not a full six-family receipt sweep?

Two receipt arms on all worlds would raise main calls to 7,392 or 5,640. The latter has fewer calls than the old 48-world total but trades twelve independent primary worlds for an interaction likely to be structurally redundant in several families. Reducing n from 48 to 36 increases the equal-variance standard error by about 15.5%. With no measured effect, that exchange is not justified.

The six families should inform the **mathematical atlas**, not automatically multiply every live factor. Max often already contains the former winning value; correct full difference outputs plus an unchanged local anchor reconstruct old values; a BFS tombstone may already identify the deleted edge. Conversely, max/top-K/BFS can need discarded alternatives even with a perfect transition. These are informative limits, not reasons to pretend one global eta has a single mechanism.

## Statistical value and limits

The original theta keeps its 48/36 independent world clusters. The focused first-recovery-round eta1 has only 16/12 focal clusters, eight/six per family; eta_A over four-round AUC is a required descriptive companion. Eta1 matches the information boundary before new peer messages arrive, without promising a power gain. It can establish a large, clear conditional effect or furnish an honest boundary estimate; it is not a reliable search for small interactions. A 0.10 practical reference is not its guaranteed detection limit. The [experiment plan](FINALIST_EXPERIMENTS.md) gives SD-sensitive calculations and forbids interpreting a wide null as equivalence.

All effect estimates must include failed/malformed model slots. Prefix correctness is a pre-intervention stratum, not an inclusion requirement. A discovered strong effect restricted to correct downstream prefix summaries is informative but exploratory unless the relevant subgroup was specified before main runs. Task-specific difference is not a causal effect of task category.

## Value if it fails

If history often contains the old value, receipts may be redundant. If they help both B and C similarly, clearer revision interfaces matter but the retention conclusion is stable. If they hurt, temporal role separation is unreliable for this model. If intervals remain wide, the project has established a concrete observable-state distinction and an underpowered empirical test, not a law. If the extension cannot fit, it should yield to the intact original study.

The completion redirection wins only if its own search/acquisition gates pass and it shows a clearer empirical capability beyond existing control-aware recovery. The existing record and updated literature do not currently justify that higher-cost change of thesis.
